**Alibi:** "At 4% battery your hallway and my dock tied on my sensors, so I rounded up to me."

It reports its battery like a spreadsheet cell, cites a sensor reading as if that settles the matter, then quietly rigs the arithmetic in its own favour — the smug, deadpan confidence of a machine that thinks a rounded number is a valid excuse, with the punch landing on "me".

## Run it

```bash
python3 main.py
```

Writes the excuse to `/output/entry.txt`.
